# Commands Reference

## Overview

This document contains the commands used during **Phase 01 – Sysmon + Splunk Cloud Integration**.

These commands were used to install and configure Sysmon, verify endpoint telemetry, configure Splunk Universal Forwarder, and validate log collection in Splunk Cloud.
---

# Sysmon Commands

## Install Sysmon

```powershell
Sysmon64.exe -accepteula -i sysmonconfig.xml
```

**Purpose**

Installs Sysmon using the specified configuration file and automatically accepts the license agreement.

---

## View Current Configuration

```powershell
Sysmon64.exe -c
```

**Purpose**

Displays the active Sysmon configuration currently running on the endpoint.

---

## Update Configuration

```powershell
Sysmon64.exe -c sysmonconfig.xml
```

**Purpose**

Updates the existing Sysmon configuration without reinstalling the service.

---

## Uninstall Sysmon

```powershell
Sysmon64.exe -u
```

**Purpose**

Removes Sysmon from the Windows system.

---

# Windows Event Viewer

## Open Event Viewer

```powershell
eventvwr.msc
```

**Purpose**

Opens Windows Event Viewer to verify Sysmon Operational logs.

---

## Sysmon Event Log Location

```text
Applications and Services Logs
└── Microsoft
     └── Windows
          └── Sysmon
               └── Operational
```

**Purpose**

Displays all events generated by Sysmon.

---

# Splunk Universal Forwarder

## inputs.conf

```ini
[WinEventLog://Microsoft-Windows-Sysmon/Operational]
disabled = 0
index = main
renderXml = true
```

**Purpose**

Configures Splunk Universal Forwarder to monitor the Sysmon Operational event log.

---

# Splunk Searches

## View All Sysmon Events

```spl
source="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
```

**Purpose**

Displays all Sysmon events received in Splunk Cloud.

---

## Search Process Creation Events

```spl
EventCode=1
```

**Purpose**

Returns Sysmon Process Creation events.

---

## Search Network Connection Events

```spl
EventCode=3
```

**Purpose**

Returns Sysmon Network Connection events.

---
